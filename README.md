# PAC-MAN_Ghost_SAO

This SAO was designed for DEF CON 34 as one of the free SAOs for NilbinSec to spread Badgelife cheer and an interest in Electrical Engineering. A total of 1000 PAC-MAN Ghost SAOs were given away, 250x of each color (Red, Blue, Purple, and Yellow)

# BOM
1x PCB
1x 2x3 Keyed IDE Header
2x 160R 0805 Resistor
2x 0807 RGB Fast Flash LEDs

# Files
Gerber Files are included with the repo with pos files for PnP if you want to do a large order.
